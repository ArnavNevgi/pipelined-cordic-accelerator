# Error Analysis

## Metrics

The project will report:

- Maximum absolute sine error
- Maximum absolute cosine error
- Mean absolute sine error
- Mean absolute cosine error
- RMS sine error
- RMS cosine error
- Maximum sine error in LSBs
- Maximum cosine error in LSBs

## Comparison Method

RTL outputs will be written to CSV and compared against Python golden outputs.

## Status

Error results will be added after simulation is complete.
