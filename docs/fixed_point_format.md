# Fixed-Point Format

## Q2.14 Format

The design uses signed Q2.14 fixed-point arithmetic.

- Total width: 16 bits
- Fractional bits: 14
- Scale factor: `2^14 = 16384`
- Approximate range: `-2.0` to `+1.9999`
- Resolution: `1 / 16384 = 0.00006103515625`

## Conversion

Floating-point values are quantized by scaling by `2^14`, rounding to an integer, and saturating to the signed 16-bit range.

```text
q214 = round(value * 16384)
```

Negative values are stored in two's-complement form in the hex test-vector file.

## Angle Format

Input angles are represented in radians using signed Q2.14 format.

The current supported range is:

```text
-pi/2 to +pi/2 radians
```

## Output Format

Sine and cosine outputs are represented using signed Q2.14 format.

## CORDIC Constants

The gain compensation constant is:

```text
CORDIC_K = round(0.607252935103 * 16384) = 9949
```

The arctangent lookup table is generated by `scripts/gen_golden.py` and recorded in `reports/atan_table_q214.txt`.
